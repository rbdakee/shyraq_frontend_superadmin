# Shyraq SuperAdmin

Внутренний веб-инструмент команды Shyraq для управления SaaS-платформой детских садов: тенанты, подписки, фичефлаги, операторские триггеры, DLQ. Аудитория — 5–20 internal users за VPN/IP-allowlist. Desktop-first (≥ 768px), light theme.

## Setup

1. `pnpm install`
2. `cp .env.example .env.local` — fill in `VITE_API_BASE_URL` (default `/api/v1`, served via Vite dev proxy to the live dev backend).
3. `pnpm dev` — Vite dev server on `http://localhost:5173`. Backend dev: `http://13.60.189.214:3000` (proxied).

## Backend integration

See [`CLAUDE.md` §3](CLAUDE.md#3-backend-integration). All endpoints under `/api/v1/*` proxied to the live dev backend in development. OpenAPI types are generated by `pnpm gen:api` and committed.

## Architecture overview

SPA on Vite 8 + React 19 + TypeScript (strict). TanStack Query for server state, Zustand for UI state (sidebar / locale / command palette / shortcuts help). shadcn/ui primitives over Tailwind v4. i18next RU + KK across 7 namespaces. In-memory access token + localStorage refresh token (Auth flow per `docs/architecture.md §6`). Route-level `React.lazy` + Suspense; mobile alert below 768px; DIY error tracking with `crypto.randomUUID()` shown on the 500 page. See [`docs/architecture.md`](docs/architecture.md) for the full layering, [`docs/DESIGN.md`](docs/DESIGN.md) for per-page specs, and [`docs/IMPLEMENTATION_PLAN.md`](docs/IMPLEMENTATION_PLAN.md) for the batch history.

## Deploy

Static build (`pnpm build` → `dist/`) on S3 + CloudFront (or Nginx/Caddy) behind a reverse proxy with IP-allowlist. CSP `default-src 'self'; img-src 'self' data:; connect-src 'self'`. HTTPS + HSTS preload. Deployment is intentionally out of scope for the development batches — see "Post-B8 Deployment" in `docs/IMPLEMENTATION_PLAN.md`.
